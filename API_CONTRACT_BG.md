# API договор — BAGER SITE LINK v1.0

Всички маршрути `/api/*` изискват активна сесия, освен `/health`. Достъпът е ограничен по роля и проект.

| Метод | Маршрут | Роли | Функция |
|---|---|---|---|
| GET | `/api/me` | всички | Профил, роля и обект |
| POST | `/api/shift/start` | всички активни участници | Започва смяна |
| POST | `/api/shift/end` | всички активни участници | Приключва смяна |
| POST | `/api/gps` | шофьор, оператор, диспечер, ръководител | Записва GPS точка |
| GET | `/api/gps/latest` | собственик, диспечер, ръководител | Последни GPS позиции |
| GET | `/api/trips` | участници | Курсове; шофьорът вижда само собствените си |
| POST | `/api/trips/new` | собственик, диспечер, ръководител | Създава курс за свободна двойка камион/шофьор |
| POST | `/api/trips/{id}/action` | шофьор, диспечер, ръководител | Променя етапа по валиден преход |
| POST | `/api/load-ticket` | собственик, диспечер, оператор, ръководител | Създава един товарен билет за курс |
| GET | `/api/dashboard` | собственик, диспечер, ръководител, клиент | Обобщение; клиентът не получава GPS |
| GET | `/api/activity` | собственик, диспечер, ръководител | Последни оперативни събития |
| POST | `/api/invitations` | собственик, диспечер | Създава еднократна покана |
| POST | `/api/invitations/{id}/revoke` | собственик, диспечер | Оттегля неизползвана покана |
| GET | `/api/assets` | собственик, диспечер, ръководител | Машини в обекта |

## Основни кодове за грешки
- `401` — няма валидна сесия.
- `403` — ролята няма право за действието.
- `404` — курс/обектът не принадлежи към сесията.
- `409` — невалиден етап, дублиран билет, липсва назначен ресурс или смяна.
- `410` — поканата е изтекла, използвана или оттеглена.
- `422` — невалидни координати, обем или времеви маркер.
